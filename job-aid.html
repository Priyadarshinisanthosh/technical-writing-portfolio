Troubleshoot a Failed Data Ingestion Job

Audience: Operations Engineers
Estimated completion time: 5–10 minutes

Portfolio Sample: The application, navigation, error codes, and workflow are fictional.

When to Use This Job Aid

Use this procedure when an ingestion job displays a FAILED status.

1. Identify the Failure

Open Operations → Jobs → Job History and select the failed job.

ItemExample
Job IDJOB-10482
Datasetcustomer_orders
Failed StageSchema Validation
Error CodeVAL-102
Start Time10:32 AM

2. Review Error Details

Expand Error Details.

Field: customer_id
Expected type: STRING
Received type: INTEGER

Determine whether the failure relates to source data, schema validation, storage access, authentication, network connectivity, or internal processing.

3. Verify the Source

Before retrying the job, confirm that:

  • Required files are available.
  • Required fields exist.
  • Field names match the registered schema.
  • Data types are compatible.
  • The source configuration references the correct environment.
Important: Do not repeatedly retry a job without identifying the original failure.

4. Run Validation

Select Actions → Validate Source and wait for validation to complete.

Expected result:

Validation Status: PASSED

If validation fails, correct the reported issue before continuing.

5. Retry the Job

Select Actions → Retry and monitor the job.

Expected progression:

QUEUED → RUNNING → COMPLETED

Escalation

Escalate when validation succeeds but processing repeatedly fails, multiple datasets fail simultaneously, the failure indicates infrastructure connectivity, authentication fails despite valid credentials, or an internal processing error repeats.

Include the Job ID, environment, timestamp, error code, failed stage, relevant log excerpt, and troubleshooting already performed. Do not include credentials or sensitive data.
