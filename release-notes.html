Nimbus Data Platform 4.6 Release Notes

Release date: August 28, 2026
Release: 4.6.0

Portfolio Sample: Nimbus Data Platform is a fictional product created to demonstrate release-note organization and change communication.

Nimbus Data Platform 4.6 introduces improved ingestion monitoring, configurable source validation, and operational enhancements for large-volume processing.

What's New

Enhanced Ingestion Monitoring

Administrators can now view detailed processing information directly from the Jobs dashboard, including current processing stage, records processed, failed-record count, start and completion time, and job duration.

Benefit: Operations teams can investigate processing issues without relying exclusively on application logs.

Source Schema Validation

Administrators can now validate an incoming dataset before processing. When validation is enabled, Nimbus compares the incoming schema with the registered destination schema, including required fields, field names, supported data types, and structural compatibility.

If validation fails, the job stops before data is written.

Improved Job Processing

The processing engine has been updated to improve workload distribution for eligible large-volume jobs. No configuration change is required for existing workloads.

Changed

The Create Job workflow now separates source-validation options from processing configuration. Existing scheduled jobs retain their current settings.

Fixed Issues

NDP-2147 — Incorrect status after service restart

Fixed an issue where interrupted jobs could continue to display RUNNING after the processing service restarted.

NDP-2191 — Incomplete schema error details

Schema validation errors now identify the affected field and expected data type.

NDP-2218 — Delayed dashboard statistics

Improved metric refresh behavior following large processing jobs.

Known Issues

NDP-2254 — Job history filtering

Filtering job history across a large date range may take longer than expected.

Workaround: Use a narrower date range when searching historical jobs.

Upgrade Considerations

  1. Complete active processing jobs.
  2. Back up the configuration database.
  3. Verify available storage capacity.
  4. Upgrade a non-production environment first.
  5. Validate API connectivity after the upgrade.
  6. Confirm scheduled jobs after deployment.
