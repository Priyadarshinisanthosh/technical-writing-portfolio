Cloud Deployment Readiness Checklist

Use this checklist before scheduling a production cloud deployment.

Portfolio Sample: This fictional checklist demonstrates infrastructure and deployment-readiness documentation.

Account

  • ☐ Target cloud account approved
  • ☐ Deployment region confirmed
  • ☐ Required service quotas reviewed
  • ☐ Deployment window approved

Network

  • ☐ VPC identified
  • ☐ Private subnets available
  • ☐ Availability Zones confirmed
  • ☐ Routing configured
  • ☐ Required firewall rules approved
  • ☐ DNS strategy confirmed
  • ☐ Administrative source ranges approved

IAM & Security

  • ☐ Deployment IAM role created
  • ☐ Required permissions reviewed
  • ☐ Encryption-key strategy approved
  • ☐ TLS certificate available
  • ☐ Secrets-management approach confirmed
  • ☐ Security review completed

Compute

  • ☐ Instance architecture selected
  • ☐ Instance sizing reviewed
  • ☐ Operating-system baseline approved
  • ☐ Storage capacity confirmed

Object Storage

  • ☐ Required buckets available
  • ☐ Encryption enabled
  • ☐ Public access blocked
  • ☐ Lifecycle requirements defined
  • ☐ Application access validated

Database

  • ☐ Managed or external PostgreSQL decision confirmed
  • ☐ Database endpoint available
  • ☐ Database connectivity validated
  • ☐ Backup policy defined
  • ☐ Availability requirements confirmed

Operations

  • ☐ Centralized logging enabled
  • ☐ Log-retention period approved
  • ☐ Alert destinations configured
  • ☐ Infrastructure alarms configured
  • ☐ Operational ownership confirmed

Final Deployment Approval

Deployment should proceed only when all mandatory prerequisites are complete, security approval has been received, network connectivity has been validated, deployment credentials have been tested, a rollback procedure is available, and the post-deployment validation plan is ready.
