# Priyadarshini Santhosh — Portfolio Website

Static portfolio website ready for GitHub Pages.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `technical-writing-portfolio`).
2. Upload the files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public portfolio URL.

## Files
- `index.html` — homepage
- `api-guide.html` — CloudVault API portfolio sample
- `runbook.html` — Azure recovery runbook sample
- `styles.css` — responsive styling

The two documentation projects are explicitly identified as portfolio simulations.
