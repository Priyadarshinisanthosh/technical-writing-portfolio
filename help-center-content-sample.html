Create and Manage Workspace Alerts

Portfolio Simulation: This fictional Help Center article is designed to demonstrate task-oriented standalone support content that stays aligned with Product UI terminology.

Workspace alerts notify selected people when activity matches conditions you define.

Before You Begin

To create an alert, you need permission to manage alerts in the workspace. People or groups you add as recipients must already have workspace access.

Create an Alert

  1. Open the workspace and select Alerts.
  2. Select Create alert.
  3. Enter an Alert name that your team will recognize.
  4. Under When should this alert run?, choose the activity and condition that should trigger the alert.
  5. Under Who should be notified?, select one or more people or groups.
  6. Choose how often the system should check the condition.
  7. Review the alert and select Create alert.

Expected result: The alert appears in the Alerts list and becomes active using the conditions you selected.

Verify an Alert

After creating an alert, open it from the Alerts list and confirm the condition, recipients, and evaluation frequency. If your environment supports test notifications, send a test before relying on the alert for a critical workflow.

Troubleshooting

I can't add a recipient

Confirm that the person or group has access to the workspace. After access is granted, return to the alert and add the recipient again.

The alert did not run

  • Confirm the alert is active.
  • Verify the configured condition matches the event you expected.
  • Check the evaluation frequency.
  • Review available alert history for processing or delivery errors.

I created the wrong condition

Edit the alert and update When should this alert run?. Review the recipients before saving your changes.
