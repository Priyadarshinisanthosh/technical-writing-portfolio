CloudVault Data Archive API

Portfolio Simulation
This documentation describes a fictional enterprise system created to demonstrate technical documentation skills. Names, endpoints, configurations, credentials, architecture, and data are illustrative and are not derived from confidential client systems.

Overview

CloudVault is a fictional REST API for archiving enterprise records that are no longer required in active storage but must remain available for retention, audit, or recovery purposes.

Audience: Application developers, integration engineers, platform administrators

API style: REST / JSON

Base URL: https://api.example-cloudvault.com/v1

Authentication: OAuth 2.0 bearer token

Quickstart

1. Obtain an access token

In production, an OAuth 2.0 identity provider would issue the token. For this sample, use a placeholder:

CLOUDVAULT_TOKEN=<access_token>

Never store production credentials in source control.

2. Create an archive

curl -X POST "https://api.example-cloudvault.com/v1/archives" \
  -H "Authorization: Bearer $CLOUDVAULT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "source": "transactions",
    "retention_period": 2555,
    "retention_unit": "days",
    "reason": "regulatory_retention"
  }'

A successful request returns 202 Accepted because archive processing occurs asynchronously.

{
  "archive_id": "arc_8F21A91",
  "status": "queued",
  "created_at": "2026-08-28T14:32:15Z"
}

Authentication

Include an OAuth 2.0 access token in the Authorization header.

Authorization: Bearer <access_token>

If the token is missing, expired, or invalid, the API returns 401 Unauthorized.

Core concepts

Archive

An archive represents data selected for movement from active storage into a retained state.

Retention policy

A retention policy defines how long archived data must be retained before it becomes eligible for deletion.

Restore job

A restore job requests temporary recovery of archived data for an authorized business, audit, or operational purpose.

API reference

Create an archive

POST /archives

Creates an asynchronous archive job.

Request body

FieldTypeRequiredDescription
sourcestringYesLogical source containing the records to archive.
retention_periodintegerYesRetention duration. Must be greater than zero.
retention_unitstringYesUnit for the retention period: days, months, or years.
reasonstringYesBusiness or compliance reason for the archive.

Example request

{
  "source": "transactions",
  "retention_period": 2555,
  "retention_unit": "days",
  "reason": "regulatory_retention"
}

Response

202 Accepted

{
  "archive_id": "arc_8F21A91",
  "status": "queued",
  "created_at": "2026-08-28T14:32:15Z"
}

Get archive status

GET /archives/{archive_id}

Returns the current state of an archive job.

curl "https://api.example-cloudvault.com/v1/archives/arc_8F21A91" \
  -H "Authorization: Bearer $CLOUDVAULT_TOKEN"

200 OK

{
  "archive_id": "arc_8F21A91",
  "source": "transactions",
  "status": "completed",
  "records_archived": 184205,
  "completed_at": "2026-08-28T14:41:02Z"
}

Possible status values are queued, processing, completed, and failed.

List archives

GET /archives

Returns archives visible to the authenticated client.

Optional query parameters:

ParameterDescription
statusFilter by archive status.
limitMaximum records returned. Default: 25. Maximum: 100.
cursorCursor returned by the previous page.

Example:

GET /v1/archives?status=completed&limit=25

Restore an archive

POST /archives/{archive_id}/restore

Requests restoration of an archived dataset.

{
  "reason": "audit_review",
  "expires_in_hours": 24
}

202 Accepted

{
  "restore_id": "rst_71AD22",
  "archive_id": "arc_8F21A91",
  "status": "queued"
}

Delete an archive

DELETE /archives/{archive_id}

Deletes an archive only when applicable retention and authorization requirements have been satisfied.

204 No Content

A production implementation should enforce retention/legal-hold rules server-side rather than relying on the client.

Error handling

Errors use a consistent JSON structure.

{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "retention_period must be greater than zero",
    "request_id": "req_091CB8"
  }
}
HTTPCodeMeaning
400INVALID_REQUESTOne or more request values are invalid.
401UNAUTHORIZEDAuthentication is missing or invalid.
403FORBIDDENThe client does not have permission for the operation.
404ARCHIVE_NOT_FOUNDThe specified archive does not exist or is not visible to the client.
409ARCHIVE_EXISTSAn equivalent active archive request already exists.
429RATE_LIMITEDThe request limit has been exceeded.
500INTERNAL_ERRORAn unexpected server error occurred.

When reporting an issue, record the HTTP status, error code, request ID, timestamp, and endpoint. Do not include access tokens or sensitive payload data.

Pagination

List operations use cursor-based pagination.

{
  "data": [
    {
      "archive_id": "arc_8F21A91",
      "status": "completed"
    }
  ],
  "next_cursor": "eyJwYWdlIjoyfQ"
}

Pass next_cursor as the cursor query parameter to retrieve the next page.

Rate limits

For this portfolio simulation, assume a limit of 600 requests per minute per client. A real implementation would document authoritative limits and response headers supplied by the service.

Troubleshooting

401 Unauthorized: Confirm the token is present, has not expired, and is intended for the correct environment.

403 Forbidden: Confirm the client has the required scope/role for the operation.

404 Archive Not Found: Verify the archive ID and confirm the authenticated client has access to it.

429 Rate Limited: Reduce request frequency and implement exponential backoff.

Archive remains in processing: Record the archive ID and request ID, check service health/monitoring, and escalate according to the operational support process.

Python example

import requests

base_url = "https://api.example-cloudvault.com/v1"
token = "<access_token>"

response = requests.post(
    f"{base_url}/archives",
    headers={
        "Authorization": f"Bearer {token}",
        "Content-Type": "application/json",
    },
    json={
        "source": "transactions",
        "retention_period": 2555,
        "retention_unit": "days",
        "reason": "regulatory_retention",
    },
    timeout=30,
)

response.raise_for_status()
print(response.json())
